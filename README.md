# Stok Takip

Python ve Tkinter ile yapılmış basit bir stok takip uygulaması.

## Özellikler
- Ürün ekleme (ad, adet, fiyat)
- Ürünleri tabloda listeleme
- Adedi 5'in altında olan ürünlerde "KRİTİK" uyarısı

## Çalıştırma
python stok_basit.py

## Planlanan özellikler
- Ürün silme
- Stok giriş/çıkış
- Verileri dosyaya kaydetme
